* About
This is a minimal literate `config.org` for Doom Emacs. It:
- sets up a minimal `init.el` (enabling TypeScript with LSP)
- provides small `config.el` tweaks for TypeScript (LSP hook + format-on-save)
- shows `packages.el` entry for `tide` (optional)

Run: ``doom sync`` after tangling / saving, then restart Emacs.

* Init (tangles to init.el)
#+BEGIN_SRC emacs-lisp :tangle ~/.doom.d/init.el
;; Minimal doom! configuration — keep only essentials and TypeScript
;; You can expand modules as needed.
(doom!
 ;; core
 :completion
 (company +childframe)        ; completion framework
 :checkers
 syntax                      ; syntax checking
 :emacs
 (dired +icons)
 :editor
 (format +onsave)            ; format on save when supported
 :tools
 (lookup)                    ; lookup / help
 lsp                         ; lsp support
 :lang
 (typescript +lsp)           ; TypeScript support with LSP
 :config
 (default +bindings +smartparens))
#+END_SRC

* Config (tangles to config.el)
#+BEGIN_SRC emacs-lisp :tangle ~/.doom.d/config.el
;; Minimal user config for TypeScript
;; Use lsp-mode and format on save. If you prefer tide, see packages.el below.

;; Ensure lsp starts for TS files
(add-hook 'typescript-mode-hook #'lsp-deferred)

;; Optional: prefer tsx for .tsx files
(add-to-list 'auto-mode-alist '("\\.tsx\\'" . typescript-tsx-mode))

;; Use Doom's format on save for typescript-mode
;; `+format-on-save-enabled-modes` is respected by `:editor (format +onsave)`
(setq +format-on-save-enabled-modes '(typescript-mode js-mode typescript-tsx-mode))

;; Example small tweak: set tab width to 2 for JS/TS
(add-hook 'typescript-mode-hook (lambda () (setq-local tab-width 2 indent-tabs-mode nil)))
(add-hook 'typescript-tsx-mode-hook (lambda () (setq-local tab-width 2 indent-tabs-mode nil)))
#+END_SRC

* Notes & workflow
- After saving/tangling, run in shell:
  - `~/.emacs.d/bin/doom sync` (or `doom sync`) to install modules/packages and regenerate files.
  - Restart Emacs.
- If you want Tide instead of LSP:
  - Uncomment `(package! tide)` in `packages.el`.
  - Configure `tide` in `config.el` (init the server in `typescript-mode-hook`).
- Add other modules to the `doom!` block in `init.el` as you need them.
